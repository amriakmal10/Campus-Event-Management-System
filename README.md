# Campus-Event-Management-System

This system is a web-based system that provides service to the admin, students, staff, and public
for participating in the event. It aims to digitalize event handling processes — from
announcement to participant registration and event reporting. Admin of the system can create
events, manage all events, and manage users of the system. Staff and students can register for
the system, register for events, manage their registration for the system and events, create
events, manage their own events, and manage participants of their own event. The public can
browse events, register for the system, and register for events.
